# Sanatan Path

A cross-platform scripture reading companion built with Expo and React Native. The same app runs on the web, iOS, and Android.

## Run locally

Install Node.js 18 or later, then from the project directory:

```sh
npm install
npm run web
```

For the native development server, run `npm start` and open the project in an iOS simulator or Android emulator. Expo Go can be used for device previews. Use `npm run typecheck` to check TypeScript or `npm run build:web` to export a static web build to `dist/`.

## Publish to GitHub Pages

The GitHub Actions workflow builds and deploys the static web export to
`https://anupamyadav7528.github.io/hindu-scripture-app/` when changes are pushed
to `main` or the MVP branch. The Expo web base path is configured for this
repository subpath; native iOS and Android builds do not use it.

In the repository's **Settings → Pages**, set the build and deployment source
to **GitHub Actions** if it is not already enabled. The workflow needs no
secrets; it uses the repository's `GITHUB_TOKEN` with only Pages deployment,
OIDC, and read-only contents permissions. To deploy manually, select the
workflow in the Actions tab and choose **Run workflow**.

## MVP features

- Responsive Home, scripture Library, chapter/verse reader, Saved, Premium, and Support screens.
- Free-to-use MVP: all included sample text, chapter summaries, bookmarks, and offline sample text are available without an account; speech playback is free for the first three Gita chapters.
- Bhagavad Gita chapter structure and brief original summaries for all 18 chapters; sample public-domain Sanskrit verses with short original English and Hindi renderings.
- Ramayana's seven Kandas and Mahabharata's eighteen Parvas, with short navigation summaries.
- Panchatantra, Vikram & Betal, Shiva Purana, and Vishnu Purana discovery cards.
- Hindi, English, Sanskrit, Tamil, Telugu, Marathi, Gujarati, and Bengali language choices. The content model is locale-keyed and falls back to English; most sample translations are intentionally not supplied yet.
- Locally persisted reading language, theme, bookmarks, offline chapter list, and a device-only premium demo flag.
- Optional local 8:00 AM daily verse reminders on iOS and Android (permission-gated; not available in the web build).
- Speech playback using Expo Speech where supported, with adjustable playback rate and a clear free limit of the first three Gita chapters.
- Light and dark reading themes; donation preview; clearly labeled future temple/puja/prasad and marketplace entry points.

## Demo boundaries

This is a product MVP, not a complete or canonical scripture edition. Gita chapters have a complete chapter index and short summaries, but only a few sample verses are included. The epic navigation is organized by Kanda and Parva without claiming to contain their full texts. Translation samples are brief original renderings; the language selector is extensible, but most localized scripture content is not seeded.

The premium buttons unlock a local demo state only. No account service, billing provider, donation processor, advertising inventory, or marketplace checkout is configured. Ad placements are visual integration seams, hidden after the local premium demo is activated. The daily verse is displayed in the app; native reminders are scheduled locally on the device and require notification permission. Offline reading saves sample chapter text on this device—there is no remote download or cross-device sync.

Audio is generated by the platform's speech engine at playback time; it is not a recorded audiobook. Speech availability, voice selection, and supported languages vary by device. Audio currently speaks a sample verse (or the daily verse for chapters without sample verses) and a chapter summary.

## Developer and administration

The developer and project owner is **Anupam Yadav**. The Support screen links to the GitHub repository, which is the owner’s current control point for source code, scripture seed data, website configuration, and GitHub Pages publishing. Repository changes deployed to `main` are published by GitHub Actions.

This static MVP does not include a secure in-app administrator account, cloud CMS, user-management system, or remote content/settings service. Changes made inside one visitor's browser or device cannot administer the public site or other users. Premium prices (₹99/month and ₹499/year), ads, donations, audio ads, puja/prasad services, and marketplace entries are product previews only; live operations require provider integrations and secure backend configuration.
